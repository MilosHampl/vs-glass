VS Glass — CSS liquid-glass lensing test (2026-09-10)

Six panes over a busy background (grid stripes + colour blobs + a text wall). Panes 2/3/6 use an SVG feDisplacementMap filter (edge-only signed-distance displacement map, generated by research/css-tests/gen_displacement.py, neutral 128/128/128 in the centre, pushed outward only within a ~34px rim). Compare pane 1 (plain blur) against 2/3 to see whether the grid lines and text visibly bend near the pane edge but stay straight in the centre.

1. blur-only control
Blur controlbackdrop-filter: blur(16px) saturate(150%). No displacement — grid lines behind should stay straight, only softened.
2. feDisplacementMap — inline SVG
Edge lensing (inline)backdrop-filter: url(#edgeLens) blur(1.5px) saturate(160%). Filter defined in this HTML document.
3. feDisplacementMap — external .svg
Edge lensing (external file)backdrop-filter: url('external.svg#edgeLensExt') ... Filter defined in a separate .svg file.

Specular rimconic-gradient border via mask-composite: exclude, brightest top-left, plus a plus-lighter sheen glow.
